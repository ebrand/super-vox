Sync to

Sends what you pick from this environment () to another one. What it replaces there is kept in a backup there first (the last five syncs' backups are kept). Anyone playing in a world that's replaced is sent out of it, and can join again at once. Players' inventories, beds and spawn points aren't sent.

Objects

Designs in the Object Designer, each with the slot it's assigned to (if any). One with the same id there is replaced; others there stay.

Figures

Players' figures as edited in the mesh editor, and how they move (the animation designer): each the whole library.

Worlds

A world goes whole: its terrain settings, every saved edit, its villages, outlaws, crops, stations, claims, track and picture. One of the same name there is replaced.
